# 02 · 整理一份课件

## 1. 归档

```bash
cw ingest ~/Downloads/Lecture\ 8\ -\ Japan.pptx
```

`cw` 会从文件名里认出课程代码（`APSS5201`、`HTI5T04` 两种写法都认），复制到对应文件夹。认不出就手动指定：

```bash
cw ingest 课件.pptx --course ~/PolyU/APSS5202_比较社会政策/
```

先用 `--dry-run` 看它打算放哪：

```bash
cw ingest 课件.pptx --dry-run
```

## 2. 四层提取

### 一条命令搞定（推荐）

```bash
cw ingest ~/Downloads/Lecture\ 8\ -\ Japan.pptx --extract
```

归档的同时做四层提取，输出形如：

```
[OK]   Week 8 - Japan (v2).pptx -> APSS5202_.../（2.4 MB）
       页数 59 · 表格 4 · 图表 3 · 备注 40 · 图片 19
       提取结果：…/APSS5202_.../.render/extract/Week 8 - Japan (v2).txt
```

支持 `.pptx`（逐格表格＋图表数据＋备注）、`.pdf`（文本＋表格，并提示是否为图片型）、`.docx`（转成 md）。
提取结果落在该课程的 `.render/extract/`，已 gitignore，不会混进课程文件夹。

**看不到「表格 N」这个数字时**，说明课件里没有原生表格（表格是图片），得走下面的 OCR。

### 手动调用（需要只提取某一页时）



一份课件里有四类信息，**只读文本会漏掉一半**：

| 层 | 内容 | 工具 |
| --- | --- | --- |
| ① 文本 | 标题、正文 | `python-pptx` / `pdfplumber` |
| ② 表格·图表·SmartArt | 数字多在表格和 chart XML 里 | 逐格读，见下 |
| ③ 图片 | 截图型图表、地图、海报 | OCR |
| ④ 演讲备注 | 教师备注常含文献页码 | `notesSlide` |

```bash
python skills/polyu-courseware-notes/scripts/extract_pptx.py 课件.pptx
```

一次拿到文本（按坐标排序）、`[TABLE]` 逐格内容、图片清单、`[NOTES]` 备注、图表数据。

## 3. 表格：这套方法里最容易出错的地方

**不要**用文本流顺序推断行列归属。一个真实事故：

> 用扁平文本读五栏课程时间表，按顺序推断列归属，把周四的课记成了周三，后续所有排课冲突结论全错。

正确做法：

```bash
python skills/polyu-courseware-notes/scripts/table_qa.py pptx 课件.pptx
python skills/polyu-courseware-notes/scripts/table_qa.py pdf 讲义.pdf --page 3
```

它会打印**表头 x 坐标**与逐格内容——列归属只能从坐标或单元格来。

**关键字段必须逐格核对**：日期、星期、时间、地点、权重、字数、页码、人名、金额。

## 4. 图片型课件

页面上 0 字符或只有标题，说明整页是图，必须 OCR：

```bash
cw ocr slide5.png
```

数字类的统计图**不要目测估读**。可接受的流程是：渲染 ≥170dpi → 找网格线标定坐标轴 → 按颜色掩码逐列取像素均值 → 换算数值，并标注「读图近似值」。

## 5. 并入笔记

提取完，把要点写进该课的 `复习笔记.md`，**一课一节**：

```markdown
## 10. Lecture 7 — 主题名（日期）

> 来源：`Week 8 - Japan (v2).pptx`（59 页）。四层提取：文本 59 页；原生表格 4 张；图表 3 张；39 条备注多为文献名。

### 10.1 核心论断
- …
```

**每条都要能回答「这话从哪来」**：课件第几页、哪位作者哪一年、还是「这是我的推断」。

## 6. 档案要能自证

新课件到了，顺手在时间线文件里记一行：上传时间、文件名、判定。

| 上传时间 | 星期 | 课件 | 判定 |
| --- | --- | --- | --- |
| 10-22 12:33 | 四 | Week 8 Japan (v1) | 当天 |
| 10-22 17:40 | 四 | Week 8 Japan (v2，59 页) | 课后修订 |

这行记录以后能救命：老师说「我早就发了」，你有时间戳。
