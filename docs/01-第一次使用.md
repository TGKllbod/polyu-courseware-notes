# 01 · 第一次使用

## 1. 装依赖

```bash
git clone https://github.com/TGKllbod/polyu-courseware-notes.git
cd polyu-courseware-notes
pip install -e .
```

需要 Python 3.9+。装完就有了 `cw` 命令。

## 2. 自检

```bash
cw doctor
```

输出形如：

```
[OK]   依赖 python-docx
[OK]   依赖 python-pptx
[OK]   LibreOffice：/Applications/LibreOffice.app/Contents/MacOS/soffice
[OK]   OCR：macOS Vision + tesseract
[!]    未找到 git——版本管理不可用
```

**`[!]` 是警告，不阻塞**。只有 `[x]` 才要处理：

| `[x]` 项 | 处理 |
| --- | --- |
| 依赖缺失 | `pip install python-docx python-pptx pdfplumber pymupdf Pillow` |
| 没有 LibreOffice | 见 [06-Windows环境](06-Windows环境.md)，`render` 会不可用 |
| 没有 OCR | 图片型课件读不出字；装 Tesseract 或换 macOS |

## 3. 建工作区

```bash
cw init --root ~/PolyU --courses "ABCD1234:课程名" "EFGH5678:另一门课"
```

生成：

```
~/PolyU/
├── .render/                    # 渲染中间产物（不用管）
├── ABCD1234_课程名/
│   └── README.md               # 课程级信息：考核、DDL、出勤、教师
└── EFGH5678_另一门课/
    └── README.md
```

`README.md` 里**只放课程级信息**，知识点另建 `复习笔记.md`。这个分工很重要：前者一年改几次，后者每周都长。

## 4. 让 AI 助手接管

把 `skills/` 下的两个目录复制进你的 AI 助手 skills 目录（以 Claude Code 为例）：

```bash
cp -R skills/* ~/.claude/skills/
```

之后你说「放了新课件」，助手会按 `SKILL.md` 走四层提取、并入笔记、生成 docx。

## 5. 可视化界面（可选）

不想记命令就用它：

```bash
cw serve
```

打开 <http://127.0.0.1:8765/>，可以：

- 看到每门课的文件数与**各讲 docx 状态**（缺 / 已生成 / 已过期——md 改过但没重新生成）
- **把课件直接拖进去**，自动归档并就地把四层提取的统计显示出来
- 点「生成 docx」重生成该课所有讲次；点「检查」跑同步与缩写检查

只监听 `127.0.0.1`，不对外暴露，也不需要登录。改端口：`cw serve --port 9000`。

## 6. 三条环境变量

| 变量 | 作用 | 默认 |
| --- | --- | --- |
| `POLYU_HOME` | 工作区根目录 | `~/PolyU` |
| `PYTHONIOENCODING` | 输出编码 | `cw` 自动设 utf-8 |
| `PYTHONPATH` | 依赖装在非标准位置时 | — |

设一次就省掉每次写 `--root`：

```bash
export POLYU_HOME="$HOME/PolyU"     # macOS / Linux
setx POLYU_HOME "%USERPROFILE%\PolyU"   # Windows（重开终端生效）
```
