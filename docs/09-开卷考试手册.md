# 09 · 做一份开卷考试手册

> 场景：课程允许开卷、不限纸张字数，考试是「25 道单选 + 1 道论述」，只有 **2 小时**。
> 目标不是「把笔记印出来」，而是**考场里 30 秒能定位、能抄出原句**。

## 一、先定形态：一份内容，两种载体

| 载体 | 用途 | 关键差别 |
| --- | --- | --- |
| **Word 详版** | 查定义、抄原句、写论述 | 连续排、目录带页码、页脚有页码 |
| **图解版 PDF** | 判断题目走哪条线、比关系 | 每讲开头一图、条目卡片化、可留白 |
| （可选）一页速查 | 临出门前 5 分钟 | 时间地点、必带物品、关键词→讲次 |

**铁律**：图解版**不许删内容**。它只是换呈现方式——用户会拿两份对照。

## 二、五步流程

### 第 1 步：单一 Markdown 源

所有内容写进一个 `开卷考试手册.md`，章节用 `## N. 标题` 编号（Word 与 PDF 都靠这个编号对齐）。

结构固定为五件套：**考试事实 → 概念速查 → 逐讲要点 → 原文定义 → 押题**。

### 第 2 步：Word 详版

```bash
python3 scripts/md_to_docx.py 开卷考试手册.md
python3 scripts/paginate_docx.py 开卷考试手册.docx --break 1,14,15
```

`paginate_docx.py` 会顺手做四件事：章节另页、段落按长度决定是否可拆、表格列宽按中英文**显示宽度**分配（中文按 2 倍）、页脚写「页码 / 总页数」。

### 第 3 步：图解版 HTML

```bash
python3 scripts/handbook_html.py 开卷考试手册.md 图解版.html --flows flows.json
```

`flows.json` 里写每讲的流程图，例如：

```json
{
  "3": [["Society", "complex, contextual"], ["State simplifies", "census · maps"],
        ["Becomes legible", "readable from centre"], ["Governed", "taxed, engineered"]]
}
```

渲染规则：`**标签** — 正文` → 左侧竖线卡片；`>` 引用 → 原文定义；表格按行数自动选样式。

### 第 4 步：PDF + 页码 + 页脚

```bash
python3 scripts/deck_pdf_pageno.py render 图解版.html 图解版.pdf
python3 scripts/deck_pdf_pageno.py toc    图解版.html 图解版.pdf 开卷考试手册.md
python3 scripts/deck_pdf_pageno.py stamp  图解版.pdf 开卷考试手册.md
```

- `toc`：把实测页码写回 HTML 目录，**迭代到稳定**；
- `stamp`：每页页脚「本页所含章节 ＋ 页码/总页数」——Chrome 打印不会自带页码，只能事后盖。

### 第 5 步：分页按 60% 定律调

```bash
python3 scripts/deck_pdf_pageno.py rule60 图解版.html 图解版.pdf 开卷考试手册.md
# 按提示记录 .force_breaks，重生成 HTML 后再跑，直到「无低起点章节」
```

**规则**：章节标题落在页面 **60% 以下**就另起一页；其余顺排。目标：平均填充 ≥80%，最空页 ≥50%。

## 三、三个最容易翻车的地方

| 坑 | 现象 | 解法 |
| --- | --- | --- |
| **目录页码全 00** | md 里那张目录表被同时渲染进 PDF，和生成的目录叠在一起 | 图解版**忽略 md 的目录表**，只用生成的 `.toc` |
| **页脚章节整体错位一页** | 0-based 与 1-based 页码混用 | 统一 1-based；`stamp` 里 `st = index + 1` |
| **出现 7% 填充的废页** | 无条件给每节加 `page-break` | 只让**标题**触发 60% 规则；表格用紧凑样式收尾 |

## 四、交付前自检清单

- [ ] 目录页码与正文**逐条**一致（脚本会自动比对）
- [ ] 每页都有页码，形态为 `12 / 31`
- [ ] 页脚章节标签与实际内容相符（尤其**一节跨两页**的情形）
- [ ] 最空页填充 ≥50%，无空白 >45% 的页
- [ ] 关键定义是**课件原句**，带课件页码
- [ ] 每讲至少一道题；综合题 ≥3 道
- [ ] 覆盖率自检跑过：课件全文抽取 → 词表比对 → 人工判定缺口
- [ ] 事实核对：年份、人数、比例、机构名，全部能在课件或录音里找到出处

## 五、这份方法的成本

以二学位一门课为例（11 讲课件、约 480 页）：

| 步骤 | 耗时 |
| --- | --- |
| 抽课件文字 + 比对 | 约 40 分钟 |
| 逐讲要点 + 原文定义 | 约 3 小时 |
| 押题（5 综合 + 11 单讲 + 范文） | 约 2 小时 |
| 排版三轮（Word／PDF／分页） | 约 1 小时 |

**回报**：考场里找一条定义从「翻 40 页」变成「看页脚 → 翻 2 页」。
