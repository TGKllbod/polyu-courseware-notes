# 07 常见错误与核对清单

> 这篇不是方法论，是**失血记录**：把踩过的坑写成检查项。
> 适用场景：长会话、多人协作、跨课程并行、临近截止。

---

## 一、先写下来，再相信记忆

**问题**：会话变长、上下文被压缩之后，**不同课程的细节会串在一起**——教师、日期、数据、要求都会混。

**真实发生过的三类错**：

| 错误 | 表现 | 后果 |
| --- | --- | --- |
| **串课** | 把 A 课的任课教师写成 B 课的 | 邮件称呼错，直接失礼 |
| **串章节** | 把「指标级 DOI」当成独立 DOI | 点开是整本书，引用不合格 |
| **串档位** | 把「低收入档替代率」写成「平均收入档」 | 核心论据错位 |

**规则**：

1. 任何**客观事实**（姓名、课程代码、日期、金额、比率）在写进交付物前，**回到文件核对一次**；
2. 工作区根目录放一份 `FACTS.md`：课程 ↔ 教师 ↔ 邮箱 ↔ 上课时间 ↔ 作业截止；
3. 不确定就写「待核」，**不要用印象补**。

```bash
# 引用前先查
grep -n "教师\|Instructor\|截止" FACTS.md
```

## 二、数字核对三步

| 步骤 | 做什么 | 反例 |
| --- | --- | --- |
| **① 回到原表** | 拿到**表号 + 行 + 列**，不靠二手转述 | 用一份转述文章里的数字，写进讲稿 |
| **② 核口径** | 净/毛、平均/中位、含不含住房或职业年金、是否「综合」口径 | 把「综合轮候时间」说成「平均轮候」 |
| **③ 查一致** | 同一指标在不同文件里必须同值同口径 | 讲稿写 66.5%，幻灯片写 65.3% |

> **顺序不能反**：先回原表，再比口径，最后才谈一致性。只做第三步，会把错的数字统一得很整齐。

## 三、跨机构数字**不能排名**

两个组织各出一套模型，即使指标同名，也往往在**参照对象、住房处理、税制建模、年份**上不同。

**处理方式（三选一）**：

1. **同源**：两国都用同一机构（含同一机构的地区版），口径一致；
2. **降级使用**：只用来显示**方向**，不排名，并在页面上写明；
3. **结构比较替代**：不比数字，比制度（谁出资、谁承担风险、谁兜底）。

**可以照抄的英文句**：

> These two figures come from different organisations, with different reference workers and different treatment of housing. Both are modelled rates for a stylised worker, not observed averages — so I use the gap to show direction, not to rank the systems.

## 四、时间范围（time binding）三件套

好的时间范围要有**三个支点**：

| 支点 | 说明 | 例子 |
| --- | --- | --- |
| **每个领域一个锚点** | 每个政策领域在窗口内至少有一个制度事件 | 长照：某年新制度上线；养老金：某年提高领取年龄 |
| **数据可得性** | 窗口内或截至窗口末有可比数据 | 官方统计到 2024 |
| **边界定义** | 什么算在内、什么只作背景 | 「窗口内通过或生效者；更早只作背景」 |

**反面教材**：拿一个与该议题无关的外部冲击（例如疫情之于养老金替代率）当理由。听众会问「这和你的指标有什么关系」，答不上。

## 五、小组作业：三处一致性

多人分头做，最容易在这三处崩：

| 检查点 | 怎么查 |
| --- | --- |
| **时间范围** | 每个人开头是否都落在同一个窗口；有没有人悄悄用了窗口外的数据 |
| **同一指标** | 同一指标在不同人的页面上是否同值、同年、同口径 |
| **术语** | 关键概念是否全组用同一个词（如「去家庭化」「权利 vs 援助」） |

另外两件事：

- **每人逐条对大纲**：把自己那节和大纲要点逐条对照，标 ✅／⚠️／❌；
- **交接句**：每节末尾必须有一句交给下一节，否则合并时会断层。

## 六、PPT 六个技术坑

| # | 坑 | 现象 | 解法 |
| --- | --- | --- | --- |
| 1 | **画布尺寸决定视觉字号** | 「我设了 20pt 怎么还小」 | 看 **pt ÷ 画布宽度**：20pt/20in = 1.6%，与 16pt/10in 相同 |
| 2 | **背景可能是页面上的组合，不在版式里** | 从空白版式新建 → 背景消失变白 | **保留原页、只删内容形状**，或把背景烘成一张图 |
| 3 | **删页没删关系** | 新页复用 `slide1.xml`，文件损坏打不开 | 删页时同时 `drop_rel`，不要只从 `sldIdLst` 移除 |
| 4 | **内嵌字体** | 文件几百 MB | 删 `embeddedFontLst` 与字体关系；正文用系统字体 |
| 5 | **图片底色与画布不一致** | 图上有一圈浅色方块 | 图片底色取画布背景色；**换图后必须重新嵌入**（pptx 存的是副本） |
| 6 | **占位符自带项目符号** | 出现「• •」双点，或缩进逐条递增 | 用占位符就别手打「•」；或改用独立文本框 |

## 七、提交前 60 秒检查

- [ ] 文件名符合**组内规则**（如 `part<N>-<说明>.pptx`）
- [ ] 页数与讲稿的 **Next 标记一一对应**
- [ ] 最小字号 ≥ 画布宽度的 **1.5%**
- [ ] 每页有**来源行**；附录（原表）在最后一页
- [ ] 讲稿里每个数字，都能在页面上找到同一个数
- [ ] 没有跨课程复用的整段文字

## 八、两条红线

**① 学术诚信**：同一份作业不得交给两门课。跨课程可以复用**研究方法与背景阅读**，但**文字必须重写**。

**② 隐私**：公开仓库里不出现真名、学号、邮箱、教师姓名、真实课程代码。用占位符（如 `ABCD1234`）。
