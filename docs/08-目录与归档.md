# 08 目录与归档

> 学期进行到一半时，工作区根目录通常会堆下 20 多个散文件：组员的 ppt、模板原件、截图、旧版本 deck。
> 这篇定一套**能长期维持**的目录约定，以及归档时必须遵守的两条硬规则。

---

## 一、根目录只留「索引类」文件

根目录是**入口**，不是仓库。只放能回答「东西在哪」的文件：

| 保留 | 作用 |
| --- | --- |
| `README.md` | 总索引：课程、进度、归档记录 |
| `课件上传时间线.md` | 课件到达日 ↔ 实际上课日 |
| `DDL汇总.md/.docx` | 全部截止日 |
| `全部课程排表.md/.docx` | 课表与教学周 |
| `课程总览.md/.docx` | 五门课概览 |

其余**一律进目录**。判断标准很简单：**这个文件回答「在哪」，还是「是什么」？** 前者留根目录，后者进目录。

---

## 二、课程目录的六个标准子目录

```
ABC1234_Course_Name/
├── README.md              ← 课程索引（留在根）
├── 复习笔记.md             ← 总源（必须留在根，见第四节）
├── ABC1234_复习笔记-第N讲.docx
├── ABC1234_课程总结.md/.docx
├── 课件/                  ← 讲课用 pptx / pdf、推荐阅读
├── 作业/                  ← 作业说明、我的草稿与成品、课堂预答
│   └── 旧版本/            ← 被替换的 deck 与讲稿
├── 行政与大纲/            ← syllabus、AR/SDF、分组名单、通知截图
├── 组员材料/              ← 组员自己发来的 ppt / 讲稿
├── 课堂录音/              ← 语音转写、录屏转写
├── 模板/                  ← 原始模板（水彩、Slidesgo 等大文件）
└── 数据与素材/            ← 数据文件、变量表、问卷（按需）
```

**层级不超过两层**。子目录内部不再分「第几周」，靠文件名排序即可。

---

## 三、归档必须先列清单，再移动，最后写日志

**三步**：

1. **列清单**：`ls` 出确切文件名，不要凭印象；
2. **移动**：逐条 `mv -n`（`-n` 不覆盖同名文件）；
3. **写日志**：在根目录 `_归档日志_YYYY-MM-DD.md` 记录「原路径 → 新路径」，一行一条。

**为什么**：移动是不可见操作。半年后想找一份文件，日志是唯一能回溯的线索。

---

## 四、两条硬规则

**① 笔记 md 与各讲 docx 必须同目录**

拆分脚本与同步检查都按**同目录配对**工作：

- `复习笔记.md` 在 `课程根/`
- `课程_复习笔记-第N讲.docx` 也必须在 `课程根/`

把 docx 挪进 `笔记/` 子目录，同步检查会报「缺件」，而实际文件还在——**误报比缺件更浪费时间**。

**② 归属不明的文件不要擅自归档**

两门课都对不上的文件（如某张不知出处的量表截图），**留在根目录并标注「待确认」**，不要塞进任何课程。塞错的代价远大于留在原地。

---

## 五、旧版本怎么处理

| 情况 | 做法 |
| --- | --- |
| 同一 deck 的 v1/v2/v3 | 全部进 `作业/旧版本/`，**当前版本**留在 `作业/` |
| 浏览器重复下载（`xxx(1).pptx`） | 先比对 md5；相同则只留一份，另一份进 `旧版本/` |
| 课件的新旧两版 | **按上传日命名或加后缀区分**，不要互相覆盖——旧版可能含新版删掉的内容（如评分细则） |

---

## 六、清理缓存与临时产物

`__pycache__/`、`.DS_Store`、`~$` 开头的 Office 锁文件、`._*` 资源叉文件都可以安全删除，但**删之前先 `ls` 确认里面只有缓存**。

```bash
ls -la path/to/__pycache__/     # 确认只有 .pyc
rm -rf path/to/__pycache__/
```

---

## 七、一次归档的检查清单

- [ ] 根目录只剩索引类文件
- [ ] 每门课顶层目录 ≤ 6 个
- [ ] `复习笔记.md` 与其 docx **同目录**
- [ ] 旧版本在 `作业/旧版本/`
- [ ] 归属不明的文件标了「待确认」
- [ ] `_归档日志_YYYY-MM-DD.md` 已写
- [ ] README 的归档记录已更新
