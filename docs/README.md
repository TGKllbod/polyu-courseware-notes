## 这套方法的四条底线

1. **一个总源，多个成品**：改内容先改 `.md`，再重新生成 `.docx`。
2. **表格必须按单元格读**，不要用文本流顺序推断行列归属。
3. **不编造**：缺信息写「未提供」，冲突就并列两种读法。
4. **交付前跑检查**：`cw check`，不要靠记忆。
